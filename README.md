# Visual HTML Explainer

A powerful, single-file HTML generator that turns simple Markdown into rich, interactive, and beautifully styled visual explainers. 

 supercharged with new visual capabilities while strictly maintaining the core guarantee: **every page is a single, offline-ready HTML file with no CDN links or external dependencies.**

## ✨ New Features

*   **🎨 Sanzo Wada Theme (`wada`)**: Instantly apply beautiful, historically significant Japanese color palettes to your text and diagrams.
*   **📊 Server-Side SVG Diagrams (`aifig`)**: Integrated with `ai-figure` to generate architecture and flow diagrams. The SVGs are fully themed, self-contained, and travel perfectly into lightboxes.
*   **✍️ Hand-Drawn Annotations (`annot-css`)**: Vendored CSS from `neat-annotations` for adding charming, hand-drawn arrows and notes to specific words in your sentences.
*   **💬 Local Feedback Row**: A vanilla JS-powered "Was this helpful?" toggle at the bottom of the page that respects the offline constraint (no tracking, no network requests).
